# Медіа сайту, які можна міняти без збірки

`hero-main.mp4` і `hero-main.webm` — відео на першому екрані головної (v4).
Щоб замінити: Add file → Upload files, завантажити файли з ТИМИ САМИМИ назвами.

Вимоги до відео:
- вертикальне 540×750 (або 1080×1500), 15–25 с, зациклюється без різкого стрибка
- без звуку, без тексту в кадрі (поверх іде заголовок і кнопка; низ кадру темніший)
- mp4 (H.264) до 2 МБ; webm (VP9) за бажанням, якщо його немає — видаліть старий webm, інакше гратиме він
- якщо файлу немає або він не вантажиться, показується фото з дизайну

Папка `v4/` перезаписується при кожній збірці, тому медіа лежать тут.
